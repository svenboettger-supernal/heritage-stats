# Heritage 2027 statistics (live)

Internal page, reads the Supabase `artifact_events` log live through the read-only RPC. The read key is pasted once and kept in the browser (localStorage), never in this repo. Refresh button, auto-refresh every minute while open. Crawler hits and direct github.io hits are filtered. Source of the event data: the hosted client page at 2027-heritage.links.getsupernal.ai.
